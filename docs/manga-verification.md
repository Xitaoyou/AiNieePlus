# 本轮验收覆盖

| 要求 | 验证 |
| --- | --- |
| 实时字体、缩框、撤销与重做 | 实际鼠标缩框与文字输入快捷键测试，字体像素与背景缓存键验证 |
| 编辑与成品分离、减少性能开销 | 背景任务禁止调用文字合成；改样式与撤销不重新解码背景 |
| 新框继承整部样式 | 新建框和检测框两条路径验证字号、粗体、自动模式继承 |
| 框右键 OCR / 删除 / 翻译 | 动作范围绑定点击的框 ID；删除可撤销 |
| 进度与日志布局 | 无任务和任务结束时隐藏进度，任务中显示；明细位于底部 |
| 当前页识别 / OCR、一键操作提示 | 有框、无框、无 OCR、同意、拒绝与补齐后翻译分支 |
| 隐藏阅读顺序、手动切页恢复跟随 | 默认收起、手动展开、识别任务暂停跟随与恢复 |
| 页面栏缩窄、缩放条与适应窗口 | 64 像素页面栏只显示序号；滑条数值与画布变换一致 |
| 大框小字、竖排标点 | 自动字号可超过旧字号；省略号和横线竖排方向验证 |
| 可编辑公共替换规则 | 默认全角省略号、规则删改、重复启用、并发合并与原翻译链路应用 |
| 术语表、禁翻表、文本替换 | 直接导航到既有公共页面；不创建独立副本 |
| 清除译文 / OCR / 框 | 当前页、整部、选中范围的内容修改与撤销 |
| 合并导入、目录、PDF | 真实目录选择、混合目录 PDF 拆页、尺寸和原件校验 |
| Fork 更新来源 | 只访问本仓库 API、支持兼容预发布包、拒绝外仓资产 |
| 上游同步 | 保留定制的正常合并、无更新不提交、冲突中止不覆盖 |

完整用例位于 tests。发布还包含真实离线模型烟测、安装后编辑器字体与缩框检查、前后端 x86-64 和依赖检查。受控翻译回复用于验证原版批处理与公共表格；不消耗用户真实接口额度。
